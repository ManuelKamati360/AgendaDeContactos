# Projecto - Agenda De Contatos
Este projeceto, tem como principal objectivo, introduzir os conceitos de desenvolvimento de um sistema/webapp em Java Web ou JEE. Bem como, a reimplementação de um sistema com uma única linguagem.  

Pois, ele irá permitir conhecer e aplicar diversas técnicas e tecnologias envolvidas no processo de desenvolvimento, como:  
- A migração de um sistema de uma stack para outra (desktop -> web); 
- Persistência e manipulação de dados em um SGBD Relacional;
- O uso da stack web base e, a sua integração com uma lingugem de programação no backend;
- Reforçar a relevância de um diagrama de projecto de desenvolvimento;
- A facilidade de implementação de um projecto após a sua prototipagem;
- E o poder do versionamento de código fonte, usando uma ferramenta especializada para tal.
